# Horizonto Klajūnai — V3.1

Исправление V3. Сайт работает без fetch, Node.js, npm и сервера.

## Обновление

Скопируйте файлы из архива непосредственно в корень существующего репозитория. Папка images/ не входит в архив — сохраните свои фотографии. Замените index.html, styles.css, config.js, README.md; добавьте или замените app.js и .nojekyll. Старые script.js и content.json не используются, их можно удалить. Сделайте commit/push, дождитесь успешного Pages deployment, обновите страницу Ctrl+F5.

## Данные

Все настройки в config.js (window.SITE). LT/EN/RU в translations, услуги и FAQ имеют три языковых поля. Открывайте index.html прямо в браузере или через GitHub Pages.

### Изображения

По умолчанию images/hero.jpg, images/owner.jpg, images/logo.png, images/gallery-01.jpg ... gallery-06.jpg. При отсутствии указанного файла сайт пробует тот же базовый путь с расширениями jpg, jpeg, webp, png, avif, в нижнем и верхнем регистре. Для другого имени замените путь в config.js. Имена чувствительны к регистру на GitHub Pages; папка должна называться images.

### Тестовые контакты

Номер +1 202 555 0147 — вымышленный номер для демонстрации tel:, не для реальных звонков. Почта orion@example.com — заглушка. Ссылки Facebook, Messenger, Instagram, WhatsApp ведут на главные страницы сервисов, а не к чужим аккаунтам. Замените их на собственные.

### Карта

address — видимый адрес, mapQuery — поиск в Google Maps. Сейчас Кафедральная площадь, Вильнюс. mapEmbedUrl можно оставить пустым, тогда URL создаётся из mapQuery, либо вставить URL из src iframe (Google Maps → Share → Embed a map). mapAutoLoad: true — карта загружается автоматически, false — по кнопке. Ссылка открытия Google Maps работает независимо от iframe. Перед публикацией проверьте требования к приватности; при необходимости используйте загрузку по согласию.

Перед публичным запуском замените тестовые данные, утвердите услуги и FAQ, уберите demoContacts/draft и noindex только после проверки.
