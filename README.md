# Horizonto Klajūnai — статический сайт

## Запуск
Откройте index.html в браузере. Node.js, npm, сборка и сервер не нужны. Для локальной разработки можно использовать VS Code Live Server.

## Версия 2
Дизайн : компактное меню, центрированный первый экран, одна секция о хозяйке и лошади, иконки услуг, слайдер со стрелками, контактная секция с картой. Цвет задаётся переменной --green в styles.css.

## Редактирование
- config.js — литовские тексты, имена, характеристики, услуги, контакты, адрес, фотографии и карта.
- images/ — реальные фото; имена и советы в images/README.md.
- styles.css — внешний вид, в том числе мобильный.
- index.html — структура и подписи секций, SEO, временный логотип-символ.
- script.js — меню, галерея, данные и загрузка карты.

## Google Maps
1. Найдите точное место на maps.google.com, выберите Share > Embed a map > Copy HTML.
2. Скопируйте только URL из атрибута src iframe в mapEmbedUrl (не весь HTML); обновите address.
3. На странице кнопка Kaip atvykti открывает Google Maps по адресу. Виджет загружается только после явного нажатия посетителя.

## GitHub Pages — демонстрация
1. Создать аккаунт horizonto-klajunai (если свободен), подтвердить почту, включить 2FA.
2. Создать public-репозиторий horizonto-klajunai.github.io (имя должно совпадать с аккаунтом + .github.io).
3. Распаковать ZIP, загрузить **содержимое** архива в корень репозитория, не вложенную папку. Файл .nojekyll при необходимости создать вручную (пустой).
4. Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
5. Проверить адрес в Settings > Pages после успешного деплоя. Изменения в main обновляют сайт.
6. Settings > Collaborators > Add people — пригласить разработчика на его личный аккаунт.

## Перед боевой публикацией
- У утверждённых услуг заменить example: true на false; неподтверждённые удалить.
- Установить draft: false в config.js и удалить meta robots noindex,nofollow из index.html. Обновить title/description при необходимости. Добавить images/logo.png (или изменить logo в config.js) для замены временного знака.
- Проверить требования к конфиденциальности, публикации контактов, Google Maps и фото, при необходимости добавить политику конфиденциальности. Кнопка карты не заменяет юридическую проверку.
- Не менять DNS, пока тестовый сайт и содержимое не утверждены.

## WordPress / существующий хостинг
Не нужно заново верстать. Если хостинг поддерживает обычные статические файлы, разместите те же HTML/CSS/JS и images/ в отдельной тестовой директории или поддомене. После проверки можно заменить WordPress статической версией с предварительным резервным копированием файлов и базы. Если WordPress действительно нужен, можно перенести разметку в собственный шаблон темы и подключить CSS/JS через wp_enqueue_style/wp_enqueue_script. Не вставляйте весь HTML-документ с head/body в Gutenberg. Не используйте основной домен одновременно для двух разных сайтов.
